# ویزارد استقرار مِهر (Mehr Wizard)

ابزار رسمی و تحت وب برای استقرار، پیکربندی پایگاه‌داده و مدیریت نودهای کلاستر مِهر روی ورکر کلودفلر.

---

## 🌟 روش‌های راه‌اندازی

### روش ۱: آسان‌ترین روش (بدون نیاز به کد و بدون ترمینال)
1. در داشبورد کلودفلر به بخش Workers & Pages > Create Application > Create Worker بروید.
2. یک نام دلخواه بگذارید و دکمه Deploy را بزنید.
3. دکمه Edit code را انتخاب کنید.
4. تمام کدهای فایل mehr-wizard.js موجود در این مخزن را کپی کرده، جایگزین کدهای ادیتور کنید و مجدداً Deploy را بزنید.
5. روی دکمه Visit site کلیک کنید تا محیط گرافیکی ویزارد بدون نیاز به هیچ ابزار دیگری باز شود.

---

### روش ۲: استقرار با Wrangler (خط فرمان)
دستورات زیر را در ترمینال اجرا کنید:

git clone https://github.com/Reeeza2005/mehr-wizard.git
cd mehr-wizard
export CLOUDFLARE_API_TOKEN="YOUR_API_TOKEN"
export CLOUDFLARE_ACCOUNT_ID="YOUR_ACCOUNT_ID"
npx wrangler deploy

---

## 📖 نحوه استفاده از محیط وب
۱. آدرس ورکر را در مرورگر باز کنید.
۲. توکن کلودفلر (API Token) خود را وارد کرده و اعتبارسنجی را بزنید.
۳. گزینه مورد نظر را انتخاب کنید:
   - Master Panel: استقرار خودکار پنل مدیریت مِهر و ساخت پایگاه‌داده ابری D1.
   - Edge Node: ساخت نود ترافیکی سبک BPB و دریافت آدرس و کلید اتصال برای ثبت در پنل.
